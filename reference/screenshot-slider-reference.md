## Screenshot caveats

- This is a **textual transcription of visible screenshot sections only**. Several sections (notably Coach Settings and whatever follows “Version 3.2.1”) were hidden/not shown.
- Screenshot headings show dates in 2025, and the visible page lists several different version headings, so no claim is made that all items belong to the same current version.
- Gameplay and simulation sliders should not be confused with real-world statistics (for example, “Three Point Shot %: 40” is a game-control value, **not** a declaration that 40% is the desired in-game 3P rate).
- No independent testing or approval of these third-party values has been performed.
